# BDD100K 데이터 카드

## 1. 기본 정보

- 데이터셋명: BDD100K
- 제공 기관: UC Berkeley / Berkeley DeepDrive
- 공식 다운로드 페이지 접근 확인일: 2026-07-28
- 공식 페이지 접근: 가능
- 사용 브라우저: Chrome
- 로그인 또는 등록: 현재 확인한 다운로드 항목에는 불필요

## 2. DashGuard에서의 사용 목적

DashGuard에서는 다음 용도로 BDD100K 사용을 검토한다.

- 차량·버스·트럭·보행자·자전거 객체 탐지
- 짧은 도로 영상에서 객체 추적 검증
- 소규모 YOLO 파인튜닝
- 다양한 시간대와 도로 환경에 대한 정성 평가

전체 데이터셋 사용은 목표가 아니며, 필요한 경우 소규모 subset만 사용한다.

## 3. 확인된 다운로드 항목

- 100K Images: 다운로드 항목 접근 가능
- 10K Images: 다운로드 항목 접근 가능
- Detection 2020 Labels: 다운로드 항목 접근 가능
- Videos: 다운로드 항목 접근 가능
- Video Parts: 버튼은 표시되지만 확인 당시 링크가 `404 Not Found`
- MOT 2020 Images: 다운로드 항목 접근 가능

### 확인한 용량

- Videos: 약 1.8TB
- 100K Images: 약 5.3GB
- Detection 2020 Labels: 약 220MB
- MOT 2020 Images:
  - 여러 ZIP 파일로 분할됨
  - 개별 파일은 약 4~5GB
  - 학습·검증·테스트 파일을 모두 받으면 상당한 저장 공간이 필요함

파일 용량은 다운로드 페이지와 파일 목록에서 2026-07-28에 확인한 값이며,
향후 제공 상태에 따라 변경될 수 있다.

## 4. 우선 검토 대상

### 객체 탐지

- 이미지: 100K Images에서 필요한 소규모 subset
- 라벨: Detection 2020 Labels
- 전체 100K 이미지 다운로드 여부는 Day 4 이전에 다시 결정

### 객체 추적

- MOT 2020 Images 또는 접근 가능한 짧은 영상
- 전체 MOT 데이터 다운로드는 현재 일정과 저장 공간을 고려하면 우선순위가 낮음
- Day 3의 추적 기능 검증은 별도의 짧은 영상으로 먼저 수행 가능

## 5. 라이선스와 이용 조건

### 공식 다운로드 페이지에서 확인한 내용

- 교육·연구·비영리 목적:
  - 사용, 복사, 수정 및 배포에 대한 허가 조항이 있음
  - 별도 비용이나 서명된 라이선스 계약 없이 사용할 수 있다고 명시됨

- 상업적 목적:
  - BDD 및 BAIR Commons 회원과 그 계열사에만 상업적 사용 권한이 명시적으로 부여됨
  - 해당 권리는 양도할 수 없음
  - 그 외의 상업적 사용은 UC Berkeley의 상업 라이선스 확인이 필요함

- 고지 의무:
  - 복사본, 수정본 또는 배포물에는 UC Regents 저작권 고지,
    사용 허가 조항, 책임 제한 조항 및 보증 부인 조항을 유지해야 함

- 책임 및 보증:
  - 데이터와 소프트웨어는 `AS IS` 상태로 제공됨
  - UC Regents는 손해에 대한 책임과 상품성·특정 목적 적합성 등의 보증을 부인함
  - 유지보수, 지원, 업데이트 또는 개선 의무가 없음

### 해석상 주의점

공식 문구의 앞부분에는 `software and/or data`가 언급되지만,
구체적인 허가 문장에는 `software and its documentation`이라는 표현이 사용된다.

공식 BDD100K 다운로드 페이지의 라이선스 영역에 게시된 문구이므로
다운로드 데이터에도 적용하려는 취지로 판단되지만, 문언의 범위가 완전히
명확하지는 않다.

따라서 다음 사용은 별도 확인 없이 진행하지 않는다.

- BDD100K를 이용한 상업 서비스
- 원본 데이터 또는 대규모 수정본의 공개 재배포
- 기업 제품이나 유료 서비스에 데이터 또는 학습 결과를 직접 포함하는 행위

### 논문 및 출처 표시

- 공식 페이지는 BDD100K 논문 인용 정보를 제공함
- 연구 보고서나 논문에서는 공식 BibTeX 인용을 사용
- DashGuard README와 결과 보고서에도 BDD100K 데이터셋과 논문 출처를 표시
- 논문 인용과 라이선스 고지 의무는 서로 별도로 관리

### 코드와 데이터 라이선스 구분

- 공식 BDD100K 도구 저장소 코드: BSD-3-Clause
- 다운로드 데이터: 공식 다운로드 페이지의 UC Berkeley 이용 조건 적용
- 도구 저장소의 BSD-3-Clause를 이미지·영상·라벨에 그대로 적용하지 않음

## 6. DashGuard 공개 범위 정책

- 공개 Git 저장소에 BDD100K 원본 이미지·영상·라벨을 포함하지 않음
- BDD100K 파일은 `data/raw/bdd100k/` 아래에 로컬로만 저장
- 원본 파일과 모델 가중치는 Git 추적에서 제외
- BDD100K는 우선 로컬 학습·평가용으로만 사용
- 공개 데모 영상은 직접 촬영했거나 이용 조건이 명확한 별도 자료를 우선 사용
- BDD100K 이미지를 공개 결과물에 포함할 필요가 있으면 저작권·라이선스 고지를 함께 표시
- 상업적 활용 가능성이 생기면 UC Berkeley의 별도 허가 필요 여부를 확인

## 7. 현재 다운로드 상태

- 오늘 다운로드한 BDD100K 파일: 없음
- 용량 확인을 위해 시작한 다운로드: 실제 파일 저장 전 취소
- 전체 데이터 다운로드: 하지 않음
- 예정 subset: 미정
- 저장 예정 위치: `data/raw/bdd100k/`
- Git 추적: 제외

## 8. 현재 결정

- Day 1:
  - 공식 다운로드 페이지 접근 가능 확인
  - 주요 파일과 용량 확인
  - 공식 라이선스 문구 확인
  - 대용량 다운로드는 수행하지 않음

- Day 3 이전:
  - 객체 추적 검증에 사용할 짧은 영상 결정
  - BDD100K MOT 전체 다운로드 없이 추적 기능부터 구현

- Day 4 이전:
  - 파인튜닝 수행 여부 결정
  - 사용할 이미지와 라벨 subset 결정
  - 학습·검증 분리 기준 결정
  - 다운로드 예상 용량과 시간을 다시 산정

## 9. 알려진 위험

- 전체 영상 데이터가 약 1.8TB로 현재 프로젝트 범위에 비해 지나치게 큼
- MOT 이미지도 여러 개의 대용량 ZIP으로 분할되어 있음
- Video Parts 링크가 현재 `404 Not Found` 상태임
- 데이터 이용 조건의 문언에 소프트웨어와 데이터 범위의 모호성이 있음
- 채용 포트폴리오가 라이선스상 비상업적 사용인지 단정하기 어려움
- 원본 프레임을 공개 데모에 포함할 경우 고지 및 배포 조건 검토가 필요함
- 추적 영상과 텔레매틱스 정보가 동일 샘플에서 모두 적합하지 않을 수 있음

## 10. 대체 경로

BDD100K 접근, 용량 또는 이용 조건이 프로젝트 일정과 맞지 않으면 다음 순서로 대체한다.

1. 직접 촬영하거나 사용 허가를 확보한 짧은 대시캠 영상
2. 공개 사용 및 재배포 조건이 명확한 도로 영상
3. 사전학습 YOLO 모델만 사용하고 파인튜닝 생략
4. 합성 텔레매틱스 CSV로 동기화 파이프라인 검증
5. BDD100K는 로컬 정량 평가에만 사용하고 공개 데모 자료에서는 제외
